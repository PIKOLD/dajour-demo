# Бриф v2 — три концепт-сайта портфолио (переделка)

Прошлая версия выглядела **дёшево**: самодельные 3D-модели из примитивов, «HUD»-рамки, шаблонные карточки. Клиенты (Кирилл и Даня — студия сайтов для малого бизнеса Перми) хотят **индивидуальные, дизайнерские, современные сайты уровня хорошей студии**, но **простые для покупателя**: за 3 секунды понятно, что это и как купить, заказ — в 2–3 нажатия, без «фильма» перед покупкой.

## Запрещено
- three.js, WebGL, самодельные 3D-модели, «HUD»/sci-fi рамки, кислотные неоновые градиенты, глассморфизм ради глассморфизма.
- Шаблонная структура «hero → три карточки в ряд → отзывы → форма» без идеи. Стоковые иконки-эмодзи вместо дизайна.
- Тяжёлые анимации, скролл-фильмы, прелоадеры, курсоры-шарики, параллакс всего подряд.
- Выдуманные награды, лицензии, «№1», фейковые таймеры, реальные бренды/адреса.

## Обязательно
- **Настоящие фото с Pexels** (бесплатная лицензия, можно коммерчески): найди через WebSearch страницы `pexels.com/photo/...-<ID>/`, собери URL `https://images.pexels.com/photos/<ID>/pexels-photo-<ID>.jpeg?auto=compress&cs=tinysrgb&w=1600` (для мелких превью w=800) и **проверь каждый** `curl -sI <url>` → должен быть `200` и `content-type: image/jpeg`. Используй только проверенные. Фото должны быть по теме, в одной цветовой гамме, без людей-знаменитостей и без чужих логотипов/вывесок. 6–12 фото на сайт. `loading="lazy"` для всех, кроме первого экрана. В подвале мелко: «Фото: Pexels».
- **Сильная арт-дирекция**, своя для каждого бизнеса (см. задание): выразительная типографика (крупные заголовки, контраст кеглей, курсив/капс), нестандартная сетка (асимметрия, наложение текста на фото, вертикальные подписи, большие номера), продуманные отступы, 2–3 цвета.
- **Моушен — тонкий и дорогой**: появление блоков (fade+translate 20px), лёгкий parallax только на 1–2 фото, бегущая строка (одна), плавные hover-эффекты на карточках/кнопках, анимированное переключение вкладок. `prefers-reduced-motion` — всё выключается.
- **Конверсия**:
  1. Первый экран: что это + главная выгода + главная кнопка + 2–3 факта. Видно сразу, без прокрутки.
  2. Быстрый путь к покупке: выбор → корзина/форма в выезжающей панели (drawer) → имя+телефон → успех. Корзина/выбор видны всегда (плавающая кнопка с суммой).
  3. Один короткий подбор (2–3 вопроса) — по желанию, если уместно.
  4. Доверие: процесс, условия, FAQ (3–5 вопросов), отзывы **только с пометкой «пример отзыва»**.
  5. Контакты: Пермь, адрес «пример», часы, телефон-пример `+7 (342) 200-00-00`, кнопки Telegram/WhatsApp.
- Плашка «Концепт-сайт · студия «Кирилл и Даня» · бренд вымышлен» (верх или низ), цены подписаны «примерные цены».
- Один файл `index.html` (CSS+JS внутри, без фреймворков), Google Fonts с кириллицей. 1440 и 390 px без горизонтального скролла (`html{overflow-x:clip}`), на телефоне липкая кнопка главного действия. Длина страницы — умеренная: 6–8 смысловых блоков.
- Проверка: `node --check` для JS (вынести во временный .js), браузер не открывать, не коммитить. Перезаписать файл целиком.
