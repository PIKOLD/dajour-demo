# ИИ-администратор на сайте D'ajour — облачная функция (5 минут)

Сайт не может хранить ключ ИИ (его бы украли), поэтому между сайтом и ИИ стоит маленькая функция в вашем Yandex Cloud. Ключ лежит только в её настройках.

## Шаги
1. Откройте **console.yandex.cloud** → ваш каталог (тот же, где AI Studio) → **Cloud Functions** → **Создать функцию**. Имя: `dajour-ai`.
2. Выберите среду **Python 3.12**, способ — **Редактор кода**. Удалите пример и вставьте целиком содержимое файла `bot/cloud/index.py`. Сохраните файл как `index.py`.
3. **Точка входа:** `index.handler`. **Таймаут:** 30 секунд. **Память:** 128 МБ.
4. **Сервисный аккаунт:** не обязателен (ключ передаём переменной).
5. **Переменные окружения** (добавить):
   - `YANDEX_API_KEY` = секрет API-ключа (тот же, что в `bot/.env`)
   - `YANDEX_FOLDER_ID` = ID каталога (тот же, что в `bot/.env`)
   - `YANDEX_MODEL` = `aliceai-llm`
   - `ALLOWED_ORIGINS` = `https://pikold.github.io,http://localhost:8765`
6. Нажмите **Сохранить изменения** (создастся версия).
7. На странице функции → **Обзор** → включите **Публичная функция**. Скопируйте **Ссылку для вызова** (вида `https://functions.yandexcloud.net/d4e...`).
8. Пришлите эту ссылку в чат — она не секретная. Я вставлю её в сайт, и консьерж начнёт отвечать через ИИ.

## Защита
- Функция отвечает только сайту (проверка Origin) и не больше 40 сообщений за 10 минут с одного адреса.
- Сайт отправляет только последние 10 сообщений, каждое до 600 символов.
- Если функция недоступна — чат на сайте сам переключается на заготовленные ответы.

## Стоимость
Вызовы Cloud Functions: в бесплатном лимите до 1 млн вызовов в месяц (уточните в тарифах). ИИ — по тарифам AI Studio, как у Telegram-бота.
