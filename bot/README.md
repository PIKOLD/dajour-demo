# ИИ-администратор «Дом D'ajour» (Telegram + YCLIENTS + YandexGPT)

Записывает на услуги со свободным временем, отвечает на вопросы по ценам и адресу, по перманенту задаёт 3 вопроса и передаёт заявку мастеру.
Время и цены бот берёт из системы, а не придумывает: ИИ понимает, что хочет клиент, а запись ведёт код.

Работает без сторонних библиотек — нужен только Python 3.10+.

## Режимы
| Что заполнено в `.env` | Как работает |
|---|---|
| ничего, кроме `TELEGRAM_BOT_TOKEN` | запись в **демо-режиме** (тестовое расписание), ответы по правилам |
| + `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` | отвечает **YandexGPT** |
| + `YCLIENTS_PARTNER_TOKEN`, `YCLIENTS_COMPANY_ID` (+ `YCLIENTS_USER_TOKEN`) | **настоящие** свободные окна и записи в YCLIENTS |

## Запуск
1. Скопируйте `.env.example` → `.env` и впишите ключи (сами, в файл — в чат ключи не пересылайте).
2. Проверка без Telegram: `python bot.py --console`
3. Бот в Telegram: `python bot.py` (пока окно открыто — бот работает; для 24/7 — на сервер).

## Где взять ключи
- **Telegram**: @BotFather → `/newbot` → токен. Свой chat id для уведомлений — у @userinfobot.
- **YandexGPT**: Yandex Cloud → создать каталог → сервисный аккаунт с ролью `ai.languageModels.user` → API-ключ. ID каталога — в консоли.
- **YCLIENTS**:
  - ID филиала — число в адресе админки YCLIENTS;
  - партнёрский токен — кабинет разработчика YCLIENTS (заявка);
  - пользовательский токен — запустите `python get_yclients_token.py`, введите логин и пароль у себя.
- В YCLIENTS должны быть заведены услуги, мастера и графики, и включена онлайн-запись.
